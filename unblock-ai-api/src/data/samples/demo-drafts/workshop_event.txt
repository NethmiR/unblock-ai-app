A lecturer or department coordinator who wants to organise a departmental
workshop, seminar or event must obtain approval before the event date.

The organiser provides the event title, the proposed date, the expected number
of attendees, and the purpose of the event.

Three things must then be approved. A hall booking is approved by the Facilities
Officer. If an external speaker is attending, an outsider access request is
approved by Security. These two can be processed at the same time and do not
depend on each other.

A refreshments request is approved by the Finance Office, but only after the
hall booking has been confirmed, because the cost estimate depends on the
venue's capacity.

Once every branch is approved, the event is confirmed and the organiser is
notified.
